##  Program Overview
*   **Institution:** Stanford University
*   **Duration:** 6 Weeks (April – June 2026)
*   **Focus:** Python fundamentals, problem decomposition, and data structures.
*   **Selection:** ~12% acceptance rate from 66,000+ applicants.

---

##  Learning Journey

### Phase 1: Foundations & Logic
*   **Weeks 1-2 (Karel the Robot):** Mastered core concepts like control flow, loops, and functions using a visual grid environment. This helped me think like a programmer before tackling complex syntax.
*   **Week 3 (Real Python):** Transitioned to standard Python. Learned user interaction, arithmetic, conditionals, and random number generation. Built interactive tools like a Haiku Generator and unit converters.

### Phase 2: Building Complexity
*   **Week 4 (Functions & Games):** Advanced to multi-parameter functions and state management. Developed strategy games like *Nimm* and *High-Low*, learning how to structure complex game logic.
*   **Week 5 (Visual Programming):** Used Stanford’s Graphics library to create dynamic visual projects, including a brick pyramid and a digital quilt, focusing on nested loops and coordinate systems.

### Phase 3: Data & Beyond
*   **Week 6 (Data Structures):** Learned to handle information efficiently using **Lists** and **Dictionaries**. Built a data pipeline to read files, count word frequency, and generate histograms.

---

##  Skills Developed
*   **Problem Decomposition:** Breaking down large problems into small, manageable functions.
*   **Algorithmic Thinking:** Planning logical solutions before writing code.
*   **Clean Code:** Writing readable, maintainable, and debuggable programs.
*   **Data Handling:** Storing and analyzing information using Python’s primary data structures.
